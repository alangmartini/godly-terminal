### Added

- **Inactive tab rest states** — inactive tabs now show a subtle rounded background tint and faded separators instead of being completely invisible
- **Dot indicator glow effects** — colored accent dots on tabs, status bar pills, and running agent indicators now emit a soft luminous glow
- **Rest-state affordance** — sidebar items, new session button, and new tab button show faint border hints at rest to signal interactivity
- **Bevel inner highlights** — all status bar pills and the title bar top edge now have subtle inner highlight lines for 3D depth
- **Faded panel separators** — sidebar vertical borders in tab bar, title bar, and status bar now use gradient-faded lines instead of hard 1px borders
- **Status bar sidebar gradient** — sidebar section of status bar now uses a vertical gradient matching the depth treatment of other bars
