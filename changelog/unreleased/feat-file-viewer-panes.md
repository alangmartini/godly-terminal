### Added
- **File viewer panes** — Open code, markdown, and image files as split panes alongside terminals. Auto-detects file type from extension with syntax-highlighted code, rendered markdown, and native image display.
- **MCP tools for agent workspace control** — `open_file_pane`, `close_pane`, `list_panes`, `update_file_pane` allow AI agents to programmatically arrange file viewers beside their terminals.
- **File watching** — File viewer panes auto-refresh when the underlying file changes on disk, enabling real-time feedback when agents edit files.
