### Fixed
- **Per-element font sizing in godly-shell** — All UI chrome text now renders at the exact pixel sizes specified in the web reference: 10px for shortcuts/badges, 11px for branch/status bar, 12px for headers/tab titles, 13px for session names/poem stanzas, 15px for poem title. Previously all text rendered at 14px (cell_height), causing visual hierarchy to be flat.
