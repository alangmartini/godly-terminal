### Changed

- **Merged title bar into tab bar** — Window controls (minimize, maximize, close) and drag handling now live directly in the tab bar, removing one chrome layer and simplifying the rendering stack.

### Added

- **Unread count badges on tabs** — Inactive tabs with new output show a gradient pill badge with the count number, breathing glow, and dark-on-accent text.
- **Window controls separator** — Subtle faded vertical line between tab content area and window chrome buttons for clearer visual grouping.
