### Added
- **Inner shadow depth cues** — Subtle shadows at terminal/tab-bar and terminal/sidebar junctions create a recessed panel effect for professional depth
- **Horizontal gradient support** — Builder and quad renderer now support left-to-right gradient fills
- **SDF anti-aliased close icon** — Window close button drawn with overlapping SDF circles for smooth diagonals at any DPI

### Changed
- **Active tab gradient fill** — Active tab now uses a subtle top-to-bottom gradient (12% lighter top) with inner bevel highlight for dimensionality
- **Status bar gradient** — Status bar background uses subtle vertical gradient for consistent depth cues
- **Sidebar active border** — Active sidebar item border uses blue-tinted accent color instead of neutral gray
- **Tab bar bevel** — Top edge of tab bar has a subtle white highlight for solid edge feel
