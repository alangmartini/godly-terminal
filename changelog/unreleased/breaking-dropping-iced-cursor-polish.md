### Changed
- **Accent-tinted cursor** — cursor body blends toward the active tab's accent color for visual coherence with selection highlights, glows, and tab chrome
- **3D cursor gradient** — subtle top-to-bottom gradient on cursor body matches the SDF lighting model used across all UI elements
- **Hollow unfocused cursor** — block cursor becomes an outline when the window loses focus (standard professional terminal behavior), with dimmed accent glow
- **Selection bounding glow** — soft Gaussian emission around the full selection area creates a spotlight effect matching the accent glow language
