### Changed
- **Depth hierarchy** — Title bar and status bar now use darker backgrounds, creating proper luminance gradient where chrome recedes and terminal content stands out
- **Active tab connects to content** — Active tab has rounded top corners with flat bottom, visually flowing into the terminal pane below; accent indicator moved to top edge
- **Sidebar active workspace accent** — Active workspace now shows a 2px accent-colored bar on the left edge for clear visual selection signal
- **Status bar shell badge** — Shell type label styled as a small pill badge; 1px top separator line visually closes the content area
- **Tab close button visibility** — Close buttons hidden on inactive tabs until directly hovered, reducing visual noise
- **Canvas-drawn window controls** — Window control buttons (minimize, maximize, close) use crisp canvas-drawn paths instead of Unicode characters
- **Sidebar polish** — Workspace item border-radius increased to 6px; terminal count badge padding and contrast improved
- **Focus glow** — Focused terminal pane gets a subtle accent-colored shadow glow for depth cue
